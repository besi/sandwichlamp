# Sandwich Lamp

## Pinout

| Pin | Function     |
|-----|--------------|
| 13  | Enable 12V   |
| 18  | Neopixel     |
| 14  | Touch 1      |
| 32  | Touch 2      |
| 4   | Touch 3      |
| 34  | Button 1     |
| 33  | Button 2     |
| 39  | Button 3     |
| 36  | Button 4     |
| 35  | Button X     |
| 27  | Radar TX     |
| 12  | Radar RX     |
| 19  | I2C SCL      |
| 23  | I2C SDA      |
| 16  | Battery Sens |
| 2   | Brightness   |
| 5   | Onboard LED  |
| 0   | OneWire      |


## Installation

```
import mip
mip.install("github:robert-hh/BME280")
```
